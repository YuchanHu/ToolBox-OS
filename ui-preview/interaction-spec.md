# 交互规范与预览

用浏览器打开 index.html。顶部导航可以切换单页或全部页面。screenshots 包含十张独立页面 PNG 与 overview.png。capture.cjs 使用本机 Playwright 与 Edge 重新导出。

## 页面操作

- 表盘上滑或点击底部箭头打开抽屉，左右滑动保持表盘。
- 抽屉左右滑动或点击两侧箭头循环选择，中央图标打开应用。返回按钮回到表盘。
- 任意圆屏顶部 100px 内向下拖动超过 45px 显示时钟，再次下滑显示控制中心。上滑直接收起全部浮层。
- 浮层通过额外 DOM 覆盖现有页面。秒表计时状态独立保存，收起浮层后继续计时。
- 控制中心支持 Wi-Fi、BLE 状态切换及亮度、音量滑块。设置入口打开设置页。
- 设置列表可纵向滚动到系统信息，点击条目进入对应页面。
- Wi-Fi 页面可关闭开关或进入重新配网。AP 页面退出按钮返回网络页。
- 秒表支持开始、暂停与复位。
- 手机页面支持选择网络、输入密码、显示密码及提交结果。

## 原型数据与实现边界

时间、电量、SSID、IP 均使用设计样例。手机提交结果为本地模拟。开关与滑块操作当前浏览器状态，设备服务接入属于确认后的固件阶段。滑块在页面重建时恢复样例值。

锁屏进入抽屉已实现逐像素跟手过渡，抽屉惯性吸附及 LVGL 时序需在固件阶段结合官方实现完成。统一动画采用 240ms 的 cubic-bezier(.22,1,.36,1)。

## 表盘选项更新

设置中的表盘样式提供数字与指针两个选项。选择后返回对应表盘，当前浏览器页面内保留选择，退出应用也返回所选表盘。指针表盘上滑或点击电量圆环进入应用抽屉，左右滑动保持当前表盘。顶部下拉采用两级浮层，第一级停留 1.5 秒后自动收起，第二级上划直接回到原页面。指针为静态设计样例 10:09:30。新增 analog.png 与 faces.png，总计十二张页面图与一张总览。表盘选择和退出应用返回已通过浏览器检查。


## 锁屏上划跟手更新

只有数字和指针钟表锁屏页可以上划进入抽屉。抽屉、设置和普通 App 上划不会跳转到抽屉。全局浮层上划直接回到原页面。移除所有底部横线。

借鉴三星手机解锁的渐隐与位移过渡，拖动时钟表随距离上移、缩小并淡出，抽屉同步上移显现。拖动阶段直接映射指针坐标，无缓动延迟。180px 对应完整进度，表盘上移 200px 并缩小至约 84%，抽屉从下方 120px、约 90% 大小逐渐进入。慢滑达到 64px 即可松手进入，短甩至少移动 16px 且向上速度达到 0.30px/ms 即可进入。重复触摸坐标保留最近移动速度，静止超过 100ms 后清除惯性。明显向下回拉或取消触摸时回弹。松手动画持续 180–280ms。

浏览器检查已验证拖动中间进度、短距离回弹、长距离进入，以及抽屉上划保持页面。unlock-drag.png 展示拖动中间帧。设备触摸响应和帧率需固件阶段实测。

首次下拉时钟小浮层增加电池图标与电量百分比，时间和电量纵向排列。原型当前显示 82%。

## 实机反馈后的 UI 重做

数字和指针表盘、应用抽屉、控制中心、设置、Wi-Fi、AP 配网和秒表均以原型尺寸重建。设备使用与原型相同的 SVG 路径导出的图标，保留原型的字号、字重、黑色背景、冷色控件和圆角。

第一级显示时间和电量，停留 1500ms 后以 200ms 动画自动收起。停留期间再次下拉进入全屏控制中心，控制中心上划直接退出。退出后保持原 App 页面。顶部第一段手势在 64px 内开始，第二段可从第一级区域继续下拉。

真实 LVGL 桌面渲染截图在 screenshots/lvgl，使用固件中的同一份页面代码及 LVGL 9.5 软件渲染器生成，硬件状态由本地固定样例提供。该工具同时验证锁屏短拖回弹、长拖进入、1500ms 超时和控制中心直接退出。设备触摸采样、面板传输和帧率仍由实机测试确认。

## 七项实测修正

锁屏释放时加入速度投影，短距离快速上甩可以继续进入抽屉。状态图标与百分比、无线开关图标与文字都作为整体居中，电池内部用实心填充表示实际电量。菜单起始高度调整至 144px，避免覆盖返回按钮。

秒表运行时左侧为计圈，暂停时为复位，右侧启停与继续。记录入口展示计圈累计时间。设备按键对应 A 为左侧操作、B 为右侧操作、A+B 长按返回。
