# 灯具实机验收清单

所有条目均待实测。表内参数来自当前固件型号能力表和 APK 静态复核。每个型号填一次实际灯具固件版本。表中「—」对应隐藏或不适用的功能，「fixed」对应固定色温且隐藏色温刻度尺，「□」对应该型号待测的功能，灯效仅测试实际菜单中出现的项目。CCT 栏格式为范围 / 步进，单位为 K。Ulanzi 的 CCT 范围与 G/M 以连接后的状态报告为准。

## 每盏灯通用检查

1. 记录灯具型号、灯具固件版本及广播 ID。按下方传输类型完成发现、连接或配对，观察状态。影器和轻装时代的广播不会返回实体灯具确认，观察实体输出。
2. 从关闭到开启再关闭。亮度试 0%、1%、65% 和 100%，带小数型号额外试 65.1% 和 65.2%。慢拖验证步进，快拖验证到达边界后反向可立即调回。确认松手后的灯具最终值。
3. 可调色温测试最小、最大及中间相邻两档。向左拖提高色温，向右拖降低色温，松手后检查最终下发值。固定色温检查页面只显示亮度刻度尺。
4. 逐一验证表内支持的 HSI、G/M 和灯效，再切回 CCT。测试 G/M 的 0、正负一档及两个端点。
5. 保存两个灯位并轮流使用，只观察选中的灯响应。关掉并重开灯具，再退出并重进 App，确认重连和保存。移除灯位后确认列表和其他灯具的行为。退出灯控后立即打开相机遥控，验收 Sony BLE 发现、连接和拍照，再返回灯控复测。
6. 记录无线环境、失败动作和相应 115200 波特率串口日志。若出现重启、卡死、卡顿或灯具误响应，注明操作顺序。
