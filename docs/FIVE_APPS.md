# 五应用扩展交付说明

计数器、倒计时、番茄钟、水平仪和天气在应用抽屉中独立注册。实际 LVGL 页面截图位于 `ui-preview/five-apps/actual/`。

## 实现入口

| 文件 | 职责 |
| --- | --- |
| `main/apps/app_{counter,timers,focus,level,weather}` | 独立生命周期、业务状态、持久化、事件和按键 |
| `main/system/extension_ui.*` | 复用公共 UI 的页面、确认框、外圈进度、控件显隐、代码绘制天气与水平仪 |
| `main/apps/common/countdown/`、`main/apps/app_level/level_reading.h` | 单调倒计时、双轴重力向量滤波与 PIN 误差 |
| `main/system/weather_service.*` | UAPI 异步 HTTPS、城市匹配、当前城市保存和天气缓存 |
| `main/system/weather_decode.*` | 实际 API 返回值解析与天气动画分类 |
| `main/hal/hal_button.cpp` | 新应用接管语义反馈时跳过原有物理按下反馈，防止重复振动 |
| `tools/generate-fonts.py` | 共享 MiSans 字体压缩、中文城市字形及角度符号 |
| `tools/ui-render/extensions.cpp` | 实际生产页面与按键流程的本地检查 |
| `tools/ui-render/export_extensions.py` | 实际 LVGL 截图导出 |

## 已实现交互

| 应用 | KEYA 短按 | KEYB 短按 | KEYA 长按 | KEYB 长按 |
| --- | --- | --- | --- | --- |
| 计数器 | -1，最低 0 | +1 | 请求屏幕确认重置 | 空闲 |
| 倒计时 | 恢复设定时长，进入待开始 | 开始、暂停、继续 | 空闲 | 空闲 |
| 番茄钟 | 专注中第一次请求退出，第二次确认退出 | 待开始时启动专注 | 空闲 | 空闲 |
| 水平仪 | 提示音开关 | 冻结、恢复 | 相对置零 | 设置、退出 PIN |
| 天气 | 上一天 | 下一天 | 空闲 | 空闲 |

双键长按优先返回表盘，单键长按在释放时派发以完成组合键仲裁。接受的单键或屏幕按钮操作使用公共按键反馈。

水平仪、番茄钟和倒计时主页面默认隐藏控制按钮。轻触唤出后保持两秒，再用 300ms 淡出。首次触摸负责唤出，隐藏状态退出命中测试。计数器主界面保留标题与数字，重置必须点击屏幕确认按钮。

倒计时采用单调微秒截止时间，提供六个预设、自定义时分秒和一个保存的常用时长。番茄钟四次完整专注后安排长休息，主动退出的专注不计入统计。

计数范围为 0 至 2147483647。连续变化合并写入 NVS，约一秒提交，正常退出再次提交。突然断电可能丢失最后一个提交窗口内的变化。

水平仪根据双轴重力向量计算总倾角和恢复方向，PIN 保存完整目标方向。180° 校准以两次各 64 个样本估计偏移，基础校准与相对零点分别管理。数值显示使用两位小数和 1.5 个百分之一度的更新滞回，PIN 误差和声音阈值使用滤波后的完整数值。提示音通过现有异步音频接口播放，退出、冻结或关闭声音时清空后续播放。

五应用在退出时清理业务资源，屏幕亮度降至零时关闭应用。现有全局下拉面板覆盖期间保留应用状态。

## 天气

在主页从中部向下拖动，出现“松开刷新”后释放。顶部系统下拉仍用于控制中心。设备可选择自动定位、按城市名搜索或输入旧行政区代码，手机配网页也可以设置城市。上次成功请求后两小时内打开应用优先使用缓存。实时温度、最多七天预报和最多二十四条逐小时记录按服务端当地日期解析。逐小时页只绘制有效记录。请求与缓存细节见 1.2 整改报告。

公开文档见 [UAPI 天气接口](https://uapis.cn/docs/api-reference/get-misc-weather)。设备侧访问日志使用 `Weather` 标签记录结果、HTTP 状态和响应字节数。

## UI 与字体

主页面使用同一份生产 LVGL 源码进行本地渲染。外圈进度、按钮位置、MiSans 字体体系、PINPOINT 数字及颜色状态均依据已确认原型实现。

20px 和 26px MiSans 扩展 GB2312 中文覆盖，采用 2bpp 压缩；其余既有字号采用 4bpp 无损压缩。字库压缩用于满足现有固件分区容量。2bpp 字体具有较少的抗锯齿灰阶。

天气输入使用圆屏内的拼音和数字键盘。大号角度采用 MiSans Semibold，内置两位小数、正负号和角度符号。

## 验证

ESP-IDF 5.5.5 通过 `tools/build.ps1` 构建至 `build-toolbox/ToolBoxOS.bin`。既有上游初始化及枚举转换警告仍会出现在构建日志中。

本地生产代码检查覆盖单调倒计时、暂停和重置、单次完成事件、四轮专注、退出确认、计数持久化、长短按仲裁、双键退出、息屏退出、城市键盘输入、日期边界、双轴倾角及 PIN 方向比较。

实际页面完成控件默认隐藏、两秒停留、淡出、字体与布局渲染检查。桌面工具提供 DIRECT 和 FULL 两种渲染模式。既有相机、秒表、触摸历史、菜单、下拉面板及显示传输检查通过。

实际页面总览为 `ui-preview/five-apps/actual/overview.png`，状态全集为 `states.png`。天气总览使用真实 API 样本，水平仪和计时截图使用明确的测试状态。

## 实机待验

- 开发板无代理网络中的 UAPI DNS、TLS、请求耗时与断网缓存。
- AMOLED 上天气动画帧率、外圈刷新、触摸唤出及淡出观感。
- BMI270 与屏幕坐标的物理方向、180° 校准、PIN、实测精度。
- 电机实际振感、声音节奏与连续达标提示效果。
- 硬件断电下最后一秒计数保存窗口。

Milwaukee 声音行为使用非阻塞近似，实际音色与误差容差需实机调试。
