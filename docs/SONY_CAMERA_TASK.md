# ToolBox OS — Sony 相机高级无线控制 APP 开发任务书（V4）

## 1. 目标与范围
在 https://github.com/YuchanHu/ToolBox-OS 现有固件上升级 Sony 相机遥控 APP，主要目标 Sony α7 V（A7M5 / ILCE-7M5），其他型号以真实能力为准。保留原系统架构、应用抽屉、表盘、控制中心、Wi-Fi/BLE、公共 UI、音频、振动和 NVS。选择蓝牙遥控直接进入原有 app_camera 功能和界面，不重新实现协议或页面，仅允许最小侵入式入口、资源和生命周期衔接。Wi-Fi 提供高级控制：拍照、录像、参数读取/设置、机身按键、控制转盘、前后拨轮、媒体列表、缩略图/预览、最新媒体快速回看及删除、反馈设置；基础完成后实现间隔拍摄、参数预设及确实支持的焦点堆栈。
正常使用独立运行，不依赖手机、路由器、互联网、电脑或外接设备。排除实时取景、视频流及播放解码、原始文件下载、RAW/HEIF 原图解码、远程格式化、相机固件修改及破解、无意义的扩展。

## 2. 环境
M5Stack StopWatch，ESP32-S3 双核 240MHz、16MB Flash、8MB PSRAM、466×466 圆形 AMOLED、CO5300、CST820、KEYA/KEYB、2.4GHz Wi-Fi、BLE、扬声器、振动马达、RTC。Windows/VSCode/ESP-IDF 5.5.5，C/C++、FreeRTOS、LVGL、Mooncake、M5GFX、Smooth UI Toolkit；具体依赖和硬件参数以当前仓库及官方资料为准，不擅自升级。沿用现有构建脚本和工具链；缺少环境时告知安装方式，不静默安装系统软件或修改全局环境。

## 4. 前置验证
先通过 Windows、alpha2go/官方 SDK 或合适工具验证 A7M5：Wi-Fi Direct、身份认证、指纹、SSH 转发、PTP/IP 双通道、SDIO、型号和能力、真实属性及允许值、修改并读回、拍照、录像启停、真实录像状态/时长或开始时间、MENU/Fn/回放/方向/SET/控制转盘/前后拨轮、媒体列表及拍摄时间、照片/视频缩略图和视频时长、指定测试媒体删除及变更事件。
删除只能使用经用户确认的无价值测试文件。没有相机时完成可独立开展的源码研究、编译和模拟测试，列出实机验收项；不能把模拟或其他型号的成功称为 A7M5 实测。基础通信未验证时，不将上层 UI 伪装为已经可用。

颜色参考：背景 #000000，卡片 #181D25，控件 #202631，主文字 #F3F6FC，次级 #98A4B7，主操作 #9DC6FF，选中文字 #081627，连接/就绪 #62D9A1，录像/删除 #FA6268，播放标识 #A0A0A0。

## 6. 入口与连接
应用抽屉保留相机入口，进入后选择 Wi-Fi 高级控制、蓝牙遥控、反馈设置。蓝牙选择后直接进入原界面。Wi-Fi 有已保存的有效配置先自动连接，否则首次配置；失败时可重试或重配。
目标架构：相机 Wi-Fi Direct AP → StopWatch STA → SSH → PTP/IP → Sony 控制协议，2.4GHz；须验证 A7M5 实际支持。正常遥控无需手机或外部中转。
首次配置两种平等方案，共用连接服务及持久化：
1. 手机辅助：复用系统临时 AP 和手机浏览器配置能力，输入相机 SSID、Wi-Fi 密码、SSH 用户名及密码及必要信息；完成后关闭临时热点，设备直连相机。无需手机 APP。
2. 本机：扫描 Wi-Fi、选择相机热点，输入 Wi-Fi 密码、SSH 用户名及密码，核对指纹并连接。
九宫格最大化按键与触摸区，小写/大写/数字/符号模式；字母布局 abc/def/ghi、jkl/mno/pqrs、tuv/wxyz/空格。每页只允许一个空格键；支持退格、多次点按循环选字、停顿/切换键/提交时确认待选字符、符号翻页、长文本不溢出。密码输入始终明文，无显隐按钮；KEYA 返回/取消、KEYB 完成字段。支持实际凭据允许的 ASCII 符号和长度，不局限字母数字。
首次读取并展示主机指纹，由用户对照相机确认，不要求逐字输入；后续验证已保存的指纹，变化须重新确认。不得盲目信任或泄漏凭据；密码不打印日志、不进 Git、不硬编码，优先复用已有安全存储及 NVS。保存连接配置、身份信息并自动重连；不强制复杂多相机管理。BLE 自动配网本阶段非必需，不为此额外逆向。
高级控制台：真实相机型号及会话状态，拍照、录像、机身控制、相册、自动化、设置。隐藏未实现或不支持的功能。

## 7. 拍照
独立页面：当前相机拍摄模式、快门、光圈、ISO、对焦模式、照片格式、相机电量、参数/相册/录像入口；以真实能力和 V4 为准。KEYB 拍照，KEYA 返回，点参数编辑，点相册直接查看最新媒体。屏幕无触摸快门键。繁忙/拒绝不能伪装成功。照片模式可通过 MOVIE 控制录像：进入独立录像控制页面，在相机允许时开始录像，无须强行修改相机模式；结束后回录像就绪，返回拍照。录像中禁止拍照。

## 8. 录像
独立页面，显示就绪状态、真实曝光参数、录像格式/帧率、电量及参数、相册、拍照入口。绿色就绪环、厚红色录像环。屏幕无可触摸启停按钮。
KEYB 第一次按开始、第二次按结束；就绪 KEYA 返回，录像中 KEYA 完全无效，组合键/长按不退出。录像中整个触摸屏锁定（包括参数、相册、返回、手势、下拉时钟及控制中心），结束恢复。录像中不拍照。
录像开始和结束在任何音量/音效设置下绝对无音效，只按配置振动；整个录制期间无操作音、错误音、完成音等。检查公共按键反馈的提前播放和重复触发。
真实相机状态为唯一可信：确认开始后显示录制，确认结束后恢复就绪，拒绝时不伪装；同步机身物理按键引起的变化，断连状态未知，不自动假定停止，重连不发送未经授权的启停。
计时优先真实录像时长/开始时间，验证语义，Free Run 时间码不能直接当时长。若无接口，记录开始指令发送时单调时钟，相机确认录制后以发送时间+500ms 为基准计算（不得逐秒累加）；HH:MM:SS，秒变化才局部更新，不全屏重绘。若机身发起且无真实时长，明确本地估算限制。

## 9. 参数
相机唯一可信：连接、重连、进入页面时读当前属性、支持/可写能力和允许值，绝不自动写入本地历史、样例或默认值。用户明确选择并确认才写入，随后读回真实值；拒绝保留真实值；机身修改优先事件同步，必要时适度刷新，不高频轮询全部。
拍照：快门、光圈、ISO、EV、白平衡、对焦模式/区域、驱动模式（单张、连拍、自拍定时）、照片格式、RAW/JPEG/HEIF、防抖等真实参数。
录像：快门、光圈、ISO、EV、白平衡、对焦模式/区域、录像文件格式、帧率、录制设置、码率、色彩采样/位深、防抖等真实参数。不得出现连拍、自拍定时、RAW/JPEG 照片质量等纯拍照参数。
V4 大数字/文字滚轮、触摸滑选、相邻值，KEYA 放弃、KEYB 确认、允许触摸应用；只读值不提供无效编辑。不能硬编码示例可选值；不同模式共享参数由相机决定。

## 10. 机身控制
按相机真实能力动态显示 MENU、Fn、回放、方向、SET、AF-ON、C1/C2/C3 等及控制转盘、前后拨轮。不要求控制器显示相机原生菜单画面。
控制转盘与方向键及 SET 融合在机身控制页面：简约深色环、四方向标识、中央 SET、冰蓝旋转指示线，无密集机械刻纹。顺/逆时针旋转发正/负步进，点按四方向和 SET 发按键；KEYB=SET、KEYA 返回。区分旋转与点按，旋转释放不能额外触发方向。15° 初始步进，实机调整；每步反馈。
独立拨轮页面仅前拨轮、后拨轮、自定义按键、AF-ON，不重复控制转盘；滑动、点击增减、连续步进。按协议正确发送按下/释放及拨轮指令，避免未释放、乱序和过期队列，不阻塞 UI。

## 11. 媒体（核心）
高级控制台、拍照、录像就绪均有相册入口，默认直接查看实际最新媒体（按真实拍摄时间等可靠元数据确定），不先选卡槽/日期/文件夹或列表。
不严格实现双卡槽区分：依协议支持读取单卡、统一列表或合并多个卡，支持时才提供选择；删除必须保留正确媒体 ID/Content ID、存储位置/卡槽和对象标识，不能仅依据文件名或列表下标。
单张回看：真实缩略图/预览、文件名、YYYY/MM/DD HH:MM:SS 具体拍摄时间、相对时间、视频标识及真实时长（如可获取）、切换、删除、列表入口。视频以灰色 #A0A0A0 播放三角区分，不出现“视频”两字，不实现播放。无真实时长不编造。
相对时间 = 本次进入回看时的当前时间 − 媒体拍摄时间，视频优先实际开始拍摄时间，不能把文件写入/修改/结束时间冒充开始时间。支持秒/分/小时/天；正确时区及语义，设备和相机时间偏差不能伪造或擅自校时。进入回看时固定统一基准，不实时计算/刷新；停留、左右切换、列表往返、删除/取消均使用同一基准；完全退出回看后重新进入才重算。如进入时“30秒前拍摄”，停留一分钟仍不变。
JPEG/RAW/RAW+JPEG/HEIF/视频仅以真实相机能返回的 Thumbnail 或 Screennail 为准；原比例矩形显示、不圆裁、不解码 RAW/HEIF 原图。获取失败显示合理占位，不以其他媒体冒充。列表辅助采用 2×2 按需加载、触摸翻页，不全量下载。
单张回看触摸左右滑动/方向按钮切换；KEYA 返回来源，KEYB 请求删除。列表 KEYB 查看选中媒体。删除确认保留预览、文件名、类型、真实删除范围；KEYA 取消、KEYB 确认，允许触摸确认/取消。RAW+JPEG 等可能属同一对象，如只能整体删除必须明确范围。真实删除成功后更新列表和缓存，事件或必要重读确认，切换相邻媒体，保持时间基准；失败不伪装成功，空列表显示“暂无媒体”。无未经确认的自动删除或批量清空。

## 12. 自动化（低于基础及媒体）
间隔拍摄：间隔、张数、实际完成数，KEYB 开始，KEYA 停止/返回，退出不再发送指令。参数预设：读并保存相机当前参数，用户主动确认应用才写；验证当前允许值，应用后读回，不在连接/重连/切换模式自动恢复。焦点堆栈参考 Alpha-Fairy，仅在实际机身/镜头/协议支持时实现，不大规模额外逆向；不支持则隐藏。

## 13. 按键及反馈
统一 KEYA 返回/取消/关闭/停止非录像任务，KEYB 确认/开始/启动/执行。配网 KEYB 确认；键盘 KEYB 完成；参数 KEYA 放弃/KEYB 应用；拍照 KEYB 快门；录像 KEYB 启停且录像中 KEYA 无效；机身 KEYB SET；拨轮无确认项不执行额外操作；相册列表 KEYB 查看，单张 KEYB 请求删除，确认页 KEYA 取消/KEYB 删除；预设确认 KEYA 取消/KEYB 应用；间隔拍摄 KEYA 停止/KEYB 开始。非录像保持原有双键长按回表盘和全局下拉交互，不改其他 APP。
所有有效实体按键、触摸按钮、键盘、转盘、拨轮、参数滚轮、确认/取消、媒体切换均支持短促音效和振动；分别配置开关、NVS 保存，音效受控制中心音量控制，音量零或关闭时无音，振动关闭不振动。复用现有接口，避免公共与应用重复反馈；高频步进反馈不阻塞、不积压。录像启停和全程强制静音优先级最高。BLE 原界面不改，若共用设置仅最小接入。

## 14. 生命周期、架构与性能
应用只前台运行，不息屏后台、不后台拍照/录像/缩略图/自动化。普通退出取消任务、关闭 PTP/IP 命令及事件、SSH，释放图像缓存及会话资源，恢复系统原网络策略（进入前的 Wi-Fi）。与已有 Wi-Fi 服务协调，不独立重写管理器。断连/关机/异常退出不擅自发送拍摄或停止命令。
合理拆分 UI、相机会话/调度/属性/录像/事件服务、Wi-Fi/SSH/PTP/IP 传输、Sony 协议、媒体与缓存、自动化；具体目录遵循仓库，不堆在单类，不引入无复用价值的复杂抽象。
网络不能阻塞 LVGL，使用现有 FreeRTOS 机制，避免竞争会话；控制命令优先于预加载，事件优先于轮询。静态图像 RGB565，缓存优先 PSRAM，只缓存当前及少量相邻媒体，按需解码，退出释放。保留原显示优化（DIRECT 双缓冲、内部 RAM DMA 条带、TE 同步、独立触摸采样，以实际源码为准），不改全局屏幕驱动；局部刷新计时、转盘、键盘、媒体，不全屏无意义重绘，不为回看相对时间启定时器，不加无用动画。
开发前实际读取分区表/固件大小；控制 SSH/加密/JPEG/字库/属性表/缓冲/内部 SRAM/PSRAM/栈开销；复用依赖，不擅自修改分区或用户空间。资源不足报告具体占用和优化选项，由用户决定。交付实际前后 BIN 大小、APP 剩余、组件体积、静态 RAM、可测内部 Heap/PSRAM/任务栈；估算不冒充实测。

## 15. 开发限制
